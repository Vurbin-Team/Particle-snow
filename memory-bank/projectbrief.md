# Project Brief

## Project Name
Particle Snow (mod id `particle-snow`, пакет `cinematic.snowstorm`, версия 1.3.0, автор в fabric.mod.json: Vurbin, лицензия CC0-1.0).

## Core Goal
Заменить ваниллный дождь/снег на плотный клиентский снегопад из своих партиклов, с туманом, звуком метели и настройками через Mod Menu + Cloth Config.

## Key Requirements
- Minecraft 26.1, Fabric (loader 0.19.5, Fabric API 0.145.1+26.1), Java 25.
- Снег виден далеко (alwaysSpawn), выглядит кинематографично.
- Работает без лагов, в том числе при быстром движении (элитры).

## Scope
- В scope: клиентская часть (`src/client`): партиклы, спавн, миксины погоды, туман, звук, конфиг.
- Вне scope: сервер (`src/main` почти пуст: только регистрация и ресурсы).
- Задача сейчас: структурная оптимизация (не уменьшение количества/спавна).
