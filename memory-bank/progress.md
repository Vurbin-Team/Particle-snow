# Progress

Спавн, физика снежинок, туман, звук метели, меню настроек, пресеты (Light/Blizzard/Magical/Cinematic), реалистичные текстуры.

## What's Left to Build

## Current Status
Патчи оптимизации применены в исходниках, сборка и замеры не выполнены.

## Known Issues
- Лаги при быстром полёте (элитры): хвост снежинок за игроком, нет отсечения по дистанции.
- Каждый партикл каждый тик делает `move()` с коллизией + аллокации (`BlockPos.containing`, AABB, Vec3).
- Спавн под землёй/крышей создаёт партиклы, которые сразу умирают.
- `MAX_PARTICLE_COUNT` из меню применяется только после перезапуска.

## Decision History
- Оптимизация = структурная (дистанция, вычисления, гейтинг), а не уменьшение количества частиц.
